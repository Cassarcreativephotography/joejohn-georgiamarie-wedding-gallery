# Joejohn & Georgiamarie — Wedding Gallery

## Publishing with GitHub Pages

1. Create a new **public** GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, `.nojekyll`, this README, and the complete `images` folder to the repository's main level.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then press **Save**.

GitHub will display the finished website address once the gallery has published.
